# Phase 9: Comprehensive Verification, Build & APK Deliverable — Implementation Plan

## Goal
Execute all verification gates across frontend and backend, build production web assets, synchronize to Capacitor Android, assemble the Android debug APK, and ensure full database preservation.

## Requirements
- VER-01: TypeScript check passes cleanly (`tsc --noEmit`).
- VER-02: Frontend vitest suite passes (100% test pass rate).
- VER-03: Backend pytest suite passes (138 tests pass).
- VER-04: Production build succeeds (`vite build`).
- VER-05: Android Capacitor build compiles debug APK (`gradlew assembleDebug`).
- VER-06: Database file `moneytrack.db` remains intact at 81,920 bytes.

## Steps
1. Run `npm --prefix frontend run typecheck` to verify complete type safety.
2. Run `npm --prefix frontend run test -- --run` to verify frontend units.
3. Run `backend\.venv\Scripts\python -m pytest backend/tests` to verify backend routes, models, and migrations.
4. Run `npm --prefix frontend run build` to build optimized web assets into `frontend/dist`.
5. Run Capacitor sync to update the Android assets.
6. Assemble Android debug APK via `.\gradlew.bat assembleDebug` in `android/`.
7. Verify APK output at `android/app/build/outputs/apk/debug/app-debug.apk` and create `release/MoneyTrack.apk`.
8. Check database size and write time for `backend/data/moneytrack.db`.
