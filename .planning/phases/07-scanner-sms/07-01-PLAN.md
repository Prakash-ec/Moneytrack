# Phase 7: Smart Receipt Scanner & SMS Review — Implementation Plan

## Goal
Redesign the Receipt Scanner and SMS Review views to match Figma Make's visual architecture, segmented tabs, upload zone with dashed border, privacy notes, and Android fallback banner.

## Requirements
- SCN-01: Replicate Receipt Scanner modal/page with 3 input modes (Upload, Camera, Paste text) in segmented tabs and extraction review.
- SMS-01: Replicate SMS Review page with unsupported browser state and Android transaction review cards.

## Steps
1. Create `frontend/src/pages/ScannerPage.tsx` and register `/scanner` in `frontend/src/App.tsx`.
2. Update `ReceiptScannerModal.tsx` and `ScannerPage.tsx` to match the exact Figma Make scanner layout:
   - Header with eyebrow `SMART CAPTURE`, title `Scan a receipt`.
   - `.segmented.scanner-tabs` for Camera, Upload, Paste text.
   - `.card.upload-zone` with dashed border, `.upload-icon`, instructions, file input / camera / textarea.
   - Processing feedback with spinner and preview.
   - `.privacy-note` indicator at bottom.
3. Update `frontend/src/pages/SmsReviewPage.tsx`:
   - When not in native Android environment (`!Capacitor.isNativePlatform()`), render the Figma Make unsupported card with `unsupported-icon`, `Android only` warning badge, description, and 3-item feature check list.
   - When on Android, display the active SMS review dashboard with styled cards and action buttons.
4. Verify with TypeScript check and Vitest test suite.
